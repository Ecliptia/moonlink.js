## Prerequisites

Before installing Moonlink.js, make sure you have:

- Node.js v22 or higher
- npm or yarn package manager
- A Discord bot application with the necessary intents

## Installing Moonlink.js

You can install Moonlink.js using npm or yarn:

::code-group
```bash [npm]
npm install moonlink.js
```

```bash [yarn]
yarn add moonlink.js
```

```bash [pnpm]
pnpm add moonlink.js
```
::

## Required Dependencies

Moonlink.js requires Discord.js to function properly. If you haven't already installed it, you can do so with:

::code-group
```bash [npm]
npm install discord.js
```

```bash [yarn]
yarn add discord.js
```

```bash [pnpm]
pnpm add discord.js
```
::

## Required Discord Intents

Your Discord bot needs specific intents to work with voice channels. Make sure to enable these intents in your Discord Developer Portal and include them when initializing your Discord.js client:

```js
const { Client, GatewayIntentBits } = require('discord.js');

const client = new Client({
  intents: [
    GatewayIntentBits.Guilds,
    GatewayIntentBits.GuildVoiceStates,
    GatewayIntentBits.GuildMessages,
    GatewayIntentBits.MessageContent,
  ],
});
```

## TypeScript Support

Moonlink.js includes TypeScript definitions out of the box. If you're using TypeScript, you can import the library like this:

```ts
import { Manager } from 'moonlink.js';
```

## Verifying Installation

To verify that Moonlink.js has been installed correctly, you can create a simple test file:

```js
const { Manager } = require('moonlink.js');

// If this doesn't throw an error, the installation was successful
console.log('Moonlink.js installed successfully!');
```
