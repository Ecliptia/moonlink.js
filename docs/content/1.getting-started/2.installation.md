## Manager

::card
---
icon: lucide:box
---

#title
Manager

#description
The `Manager` class is the core of the Moonlink.js library, responsible for managing nodes, players, and handling events. It extends the `EventEmitter` class from Node.js, allowing it to emit and listen to custom events.

#content
The `Manager` class initializes the library, manages connections to nodes, and handles player creation and deletion. It also provides methods for searching tracks and managing voice states.

## Properties

::field-group
  ::field{name="initialize" type="boolean" defaultValue="false"}
  Indicates whether the manager has been initialized.
  ::
  ::field{name="options" type="IOptionsManager" required}
  Configuration options for the manager.
  ::
  ::field{name="sendPayload" type="Function" required}
  A function to send payloads to the Discord gateway.
  ::
  ::field{name="nodes" type="NodeManager" required}
  Manages the nodes connected to the manager.
  ::
  ::field{name="players" type="PlayerManager" required}
  Manages the players created by the manager.
  ::
  ::field{name="version" type="string" required}
  The version of the Moonlink.js library.
  ::
  ::field{name="database" type="Database" required}
  Handles database operations for the manager.
  ::
::

## Methods

::field-group
  ::field{name="init (clientId: string)" type="void"}
  Initializes the manager with the provided client ID.
  ::
  ::field{name="search (options: { query: string; source?: TSearchSources; node?: string; requester?: unknown })" type="Promise<SearchResult>"}
  Searches for tracks based on the provided query and options.
  ::
  ::field{name="packetUpdate (packet: any)" type="Promise<void>"}
  Handles voice state and server updates from Discord.
  ::
  ::field{name="attemptConnection (guildId: string)" type="Promise<boolean>"}
  Attempts to establish a voice connection for the specified guild.
  ::
  ::field{name="createPlayer (config: IPlayerConfig)" type="Player"}
  Creates a new player for the specified guild.
  ::
  ::field{name="getPlayer (guildId: string)" type="Player"}
  Retrieves the player for the specified guild.
  ::
  ::field{name="hasPlayer (guildId: string)" type="boolean"}
  Checks if a player exists for the specified guild.
  ::
  ::field{name="deletePlayer (guildId: string)" type="boolean"}
  Deletes the player for the specified guild.
  ::
  ::field{name="getAllPlayers ()" type="Map<string, Player>"}
  Retrieves all players managed by the manager.
  ::
::
