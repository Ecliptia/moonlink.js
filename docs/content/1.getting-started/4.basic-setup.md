## Prerequisites

Before setting up Moonlink.js, make sure you have:

1. Installed Moonlink.js and its dependencies
2. Set up Lavalink following the [official documentation](https://lavalink.dev/) and have it running
3. Created a Discord bot with the necessary intents

## Creating a Manager Instance

The first step in using Moonlink.js is to create a `Manager` instance. The Manager is the main entry point for Moonlink.js and handles the connection to Lavalink nodes, creates players, and manages events.

### JavaScript Example

```js
const { Client, GatewayIntentBits } = require('discord.js');
const { Manager } = require('moonlink.js');

// Create a new Discord client
const client = new Client({
  intents: [
    GatewayIntentBits.Guilds,
    GatewayIntentBits.GuildVoiceStates,
    GatewayIntentBits.GuildMessages,
    GatewayIntentBits.MessageContent,
  ],
});

// Create a new Moonlink Manager
const manager = new Manager({
  nodes: [
    {
      host: 'localhost', // Lavalink host
      port: 2333, // Lavalink port
      password: 'youshallnotpass', // Lavalink password
      secure: false, // Whether to use SSL/TLS
    },
  ],
  sendPayload: (guildId, payload) => {
    // Send voice state updates to Discord
    const guild = client.guilds.cache.get(guildId);
    if (guild) guild.shard.send(payload);
  },
});

// Attach the manager to the client for easy access
client.manager = manager;
```

## Manager Configuration Options

The `Manager` constructor accepts several options to customize its behavior:

### Required Options

| Option | Type | Description |
| ------ | ---- | ----------- |
| `nodes` | `Array<Object>` | An array of Lavalink node configurations. |
| `sendPayload` | `Function` | A function that sends voice state updates to Discord. |

### Node Options

| Option | Type | Default | Description |
| ------ | ---- | ------- | ----------- |
| `host` | `String` | `'localhost'` | The hostname or IP address of the Lavalink server. |
| `port` | `Number` | `2333` | The port number of the Lavalink server. |
| `password` | `String` | `'youshallnotpass'` | The password for the Lavalink server. |
| `secure` | `Boolean` | `false` | Whether to use SSL/TLS for the connection. |
| `identifier` | `String` | `null` | A unique identifier for the node. |
| `regions` | `Array<String>` | `[]` | An array of voice regions this node is optimal for. |

### Manager Options

| Option | Type | Default | Description |
| ------ | ---- | ------- | ----------- |
| `clientName` | `String` | `'Moonlink.js'` | The client name to send to Lavalink. |
| `shards` | `Number` | `1` | The number of shards your bot is using. |
| `autoPlay` | `Boolean` | `false` | Whether to automatically play the next track in the queue. |
| `defaultVolume` | `Number` | `100` | The default volume for players (0-1000). |
| `reconnectTimeout` | `Number` | `5000` | The time to wait before reconnecting to a node (in ms). |
| `reconnectTries` | `Number` | `3` | The number of reconnect attempts before giving up. |
| `defaultSearchPlatform` | `String` | `'ytsearch'` | The default search platform to use. |
| `playerOptions` | `Object` | `{}` | Options for the Player class. |
| `database` | `Object` | `{}` | Options for the database. |
| `plugins` | `Array<Plugin>` | `[]` | An array of plugins to use. |

## Initializing the Manager

Once you've created a Manager instance, you need to initialize it when your bot is ready. This will connect to all the configured Lavalink nodes.

```js
// When the client is ready, initialize the Manager
client.once('ready', () => {
  console.log(`Logged in as ${client.user.tag}`);
  client.manager.init(client.user.id);
});
```

The `init` method takes the client ID of your Discord bot as a parameter. This is required for the Manager to function correctly.

## Handling Voice State Updates

To ensure Moonlink.js works correctly with Discord's voice system, you need to handle voice state updates:

```js
// Handle voice state updates
client.on('raw', (packet) => {
  client.manager.packetUpdate(packet);
});
```

This passes all raw packets from Discord to Moonlink.js, which will filter out the voice state updates it needs.

## Setting Up Event Listeners

Moonlink.js emits various events that you can listen to. Here are some important events to handle:

```js
// Node events
client.manager.on('nodeConnect', (node) => {
  console.log(`Node ${node.identifier} connected!`);
});

client.manager.on('nodeDisconnect', (node) => {
  console.log(`Node ${node.identifier} disconnected!`);
});

client.manager.on('nodeError', (node, error) => {
  console.error(`Node ${node.identifier} encountered an error:`, error);
});

// Player events
client.manager.on('trackStart', (player, track) => {
  const channel = client.channels.cache.get(player.textChannelId);
  if (channel) channel.send(`Now playing: **${track.title}**`);
});

client.manager.on('trackEnd', (player, track) => {
  console.log(`Track ended: ${track.title}`);
});

client.manager.on('queueEnd', (player) => {
  const channel = client.channels.cache.get(player.textChannelId);
  if (channel) channel.send('Queue ended!');
  
  // Optionally disconnect after a delay
  setTimeout(() => {
    if (!player.playing && player.queue.size === 0) {
      player.destroy();
      if (channel) channel.send('Disconnected due to inactivity.');
    }
  }, 30000); // 30 seconds
});
```

## Searching for Tracks

You can search for tracks using the `search` method of the Manager:

```js
// Search for a track
const result = await client.manager.search('Never Gonna Give You Up');

// You can also specify the search source
const result = await client.manager.search({
  query: 'Never Gonna Give You Up',
  source: 'youtube', // 'youtube', 'soundcloud', etc.
});

// Check if there are any tracks
if (result.tracks.length > 0) {
  console.log(`Found ${result.tracks.length} tracks!`);
  
  // Access the first track
  const track = result.tracks[0];
  console.log(`Track title: ${track.title}`);
  console.log(`Track author: ${track.author}`);
  console.log(`Track duration: ${track.duration}`);
  console.log(`Track URI: ${track.uri}`);
}
```

The search result will contain information about the tracks found, including title, author, duration, and URI.

## Complete Example

Here's a complete example of setting up Moonlink.js with Discord.js:

```js
const { Client, GatewayIntentBits } = require('discord.js');
const { Manager } = require('moonlink.js');

// Create a new Discord client
const client = new Client({
  intents: [
    GatewayIntentBits.Guilds,
    GatewayIntentBits.GuildVoiceStates,
    GatewayIntentBits.GuildMessages,
    GatewayIntentBits.MessageContent,
  ],
});

// Create a new Moonlink Manager
client.manager = new Manager({
  nodes: [
    {
      host: 'localhost',
      port: 2333,
      password: 'youshallnotpass',
      secure: false,
      identifier: 'Main Node',
    },
  ],
  sendPayload: (guildId, payload) => {
    const guild = client.guilds.cache.get(guildId);
    if (guild) guild.shard.send(payload);
  },
  defaultVolume: 100,
  autoPlay: true,
});

// When the client is ready, initialize the Manager
client.once('ready', () => {
  console.log(`Logged in as ${client.user.tag}`);
  client.manager.init(client.user.id);
});

// Handle voice state updates
client.on('raw', (packet) => {
  client.manager.packetUpdate(packet);
});

// Node events
client.manager.on('nodeConnect', (node) => {
  console.log(`Node ${node.identifier} connected!`);
});

client.manager.on('nodeDisconnect', (node) => {
  console.log(`Node ${node.identifier} disconnected!`);
});

client.manager.on('nodeError', (node, error) => {
  console.error(`Node ${node.identifier} encountered an error:`, error);
});

// Player events
client.manager.on('trackStart', (player, track) => {
  const channel = client.channels.cache.get(player.textChannelId);
  if (channel) channel.send(`Now playing: **${track.title}**`);
});

client.manager.on('trackEnd', (player, track) => {
  console.log(`Track ended: ${track.title}`);
});

client.manager.on('queueEnd', (player) => {
  const channel = client.channels.cache.get(player.textChannelId);
  if (channel) channel.send('Queue ended!');
  
  // Disconnect after a delay
  setTimeout(() => {
    if (!player.playing && player.queue.size === 0) {
      player.destroy();
      if (channel) channel.send('Disconnected due to inactivity.');
    }
  }, 30000); // 30 seconds
});

// Handle commands (basic example)
client.on('messageCreate', async (message) => {
  if (message.author.bot || !message.guild) return;
  
  if (message.content.startsWith('!play')) {
    // Check if the user is in a voice channel
    const voiceChannel = message.member.voice.channel;
    if (!voiceChannel) {
      return message.reply('You need to be in a voice channel to use this command!');
    }
    
    // Get the search query
    const query = message.content.slice(6).trim();
    if (!query) {
      return message.reply('Please provide a song to play!');
    }
    
    // Create a player or get an existing one
    const player = client.manager.createPlayer({
      guildId: message.guild.id,
      voiceChannelId: voiceChannel.id,
      textChannelId: message.channel.id,
      autoPlay: true,
    });
    
    // Connect to the voice channel
    player.connect();
    
    // Search for the track
    const result = await client.manager.search(query);
    
    if (!result.tracks.length) {
      return message.reply('No results found!');
    }
    
    // Add the track to the queue
    player.queue.add(result.tracks[0]);
    
    // Start playback if not already playing
    if (!player.playing) {
      player.play();
    }
    
    message.reply(`Added to queue: **${result.tracks[0].title}**`);
  }
});

// Login to Discord
client.login('YOUR_BOT_TOKEN');
```
