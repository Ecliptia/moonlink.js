O Moonlink.js utiliza vários tipos TypeScript para definir valores específicos e garantir a consistência em toda a biblioteca. Estes tipos são essenciais para o desenvolvimento com o Moonlink.js, pois fornecem validação de valores e documentação para os valores utilizados na biblioteca.

::alert{type="info" icon="lucide:info"}
Os types do Moonlink.js estão disponíveis através do módulo principal e podem ser importados diretamente.
::

---

## Types de Pesquisa

### TSearchSources

::field{name="TSearchSources" type="type"}
Define as fontes de pesquisa suportadas.
::

```typescript
type TSearchSources = "youtube" | "youtubemusic" | "soundcloud" | string;
```

Este tipo define as fontes de pesquisa suportadas pelo Moonlink.js. As fontes padrão são "youtube", "youtubemusic" e "soundcloud", mas também pode ser qualquer string para fontes personalizadas.

**Exemplo**

```typescript
// Pesquisar no YouTube
const result = await manager.search({
  query: "Never Gonna Give You Up",
  source: "youtube"
});

// Pesquisar no SoundCloud
const result = await manager.search({
  query: "Never Gonna Give You Up",
  source: "soundcloud"
});

// Pesquisar no YouTube Music
const result = await manager.search({
  query: "Never Gonna Give You Up",
  source: "youtubemusic"
});
```

## Types de Resultado

### TLoadResultType

::field{name="TLoadResultType" type="type"}
Define os tipos de resultado de carregamento.
::

```typescript
type TLoadResultType =
  | "track"
  | "playlist"
  | "search"
  | "empty"
  | "error"
  | TLoadResultNodeLinkType;
```

Este tipo define os possíveis tipos de resultado ao carregar faixas. Os valores padrão são:

| Valor | Descrição |
|-------|-----------|
| `track` | Uma única faixa foi carregada. |
| `playlist` | Uma playlist foi carregada. |
| `search` | Resultados de pesquisa foram carregados. |
| `empty` | Nenhum resultado foi encontrado. |
| `error` | Ocorreu um erro ao carregar. |

Além disso, o tipo também inclui os valores de `TLoadResultNodeLinkType` para suporte ao NodeLink.

### TLoadResultNodeLinkType

::field{name="TLoadResultNodeLinkType" type="type"}
Define os tipos de resultado de carregamento específicos do NodeLink.
::

```typescript
type TLoadResultNodeLinkType = 
  | "short"
  | "album"
  | "artist"
  | "playlist"
  | "station"
  | "podcast"
  | "show";
```

Este tipo define os possíveis tipos de resultado ao carregar faixas usando o NodeLink. Os valores são:

| Valor | Descrição |
|-------|-----------|
| `short` | Um vídeo curto foi carregado. |
| `album` | Um álbum foi carregado. |
| `artist` | Um artista foi carregado. |
| `playlist` | Uma playlist foi carregada. |
| `station` | Uma estação foi carregada. |
| `podcast` | Um podcast foi carregado. |
| `show` | Um show foi carregado. |

## Types de Nó

### TSortTypeNode

::field{name="TSortTypeNode" type="type"}
Define os tipos de ordenação para nós.
::

```typescript
type TSortTypeNode =
  | "players"
  | "playingPlayers"
  | "memory"
  | "cpuLavalink"
  | "cpuSystem"
  | "uptime"
  | "random";
```

Este tipo define os possíveis critérios de ordenação para nós. Os valores são:

| Valor | Descrição |
|-------|-----------|
| `players` | Ordenar por número de players. |
| `playingPlayers` | Ordenar por número de players reproduzindo. |
| `memory` | Ordenar por uso de memória. |
| `cpuLavalink` | Ordenar por uso de CPU do Lavalink. |
| `cpuSystem` | Ordenar por uso de CPU do sistema. |
| `uptime` | Ordenar por tempo de atividade. |
| `random` | Ordenar aleatoriamente. |

**Exemplo**

```typescript
// Configurar o Manager para ordenar nós por uso de CPU
const manager = new Manager({
  nodes: [
    // ... configurações de nós
  ],
  options: {
    sortTypeNode: "cpuLavalink"
  }
});
```

## Types de Player

### TPlayerLoop

::field{name="TPlayerLoop" type="type"}
Define os modos de loop para players.
::

```typescript
type TPlayerLoop = "off" | "track" | "queue";
```

Este tipo define os possíveis modos de loop para players. Os valores são:

| Valor | Descrição |
|-------|-----------|
| `off` | Loop desativado. |
| `track` | Loop de faixa única. |
| `queue` | Loop de toda a fila. |

**Exemplo**

```typescript
// Configurar um player com loop de faixa
const player = manager.createPlayer({
  guildId: "123456789012345678",
  voiceChannelId: "123456789012345678",
  textChannelId: "123456789012345678",
  loop: "track"
});

// Alterar o modo de loop
player.setLoop("queue");
```

### TTrackEndType

::field{name="TTrackEndType" type="type"}
Define os tipos de término de faixa.
::

```typescript
type TTrackEndType =
  | "queueEnd"
  | "loadFailed"
  | "stopped"
  | "replaced"
  | "cleanup"
  | "finished";
```

Este tipo define os possíveis motivos para o término de uma faixa. Os valores são:

| Valor | Descrição |
|-------|-----------|
| `queueEnd` | A fila terminou. |
| `loadFailed` | Falha ao carregar a faixa. |
| `stopped` | A reprodução foi interrompida. |
| `replaced` | A faixa foi substituída. |
| `cleanup` | Limpeza do player. |
| `finished` | A faixa terminou normalmente. |

**Exemplo**

```typescript
// Ouvir o evento de término de faixa
manager.on("trackEnd", (player, track, reason) => {
  if (reason === "finished") {
    console.log(`A faixa ${track.title} terminou normalmente.`);
  } else if (reason === "stopped") {
    console.log(`A faixa ${track.title} foi interrompida.`);
  }
});
```

## Uso com TypeScript

Ao desenvolver com TypeScript, você pode importar esses tipos diretamente do Moonlink.js para obter verificação de tipo estática:

```typescript
import { 
  TSearchSources, 
  TLoadResultType, 
  TSortTypeNode, 
  TPlayerLoop, 
  TTrackEndType 
} from "moonlink.js";

// Usar os tipos em suas funções
function createPlayer(guildId: string, loop: TPlayerLoop = "off") {
  return manager.createPlayer({
    guildId,
    voiceChannelId: "123456789012345678",
    textChannelId: "123456789012345678",
    loop
  });
}

// Usar os tipos em manipuladores de eventos
manager.on("trackEnd", (player, track, reason: TTrackEndType) => {
  // Lógica baseada no motivo do término
});

// Usar os tipos para configuração
const searchOptions: { query: string; source: TSearchSources } = {
  query: "Never Gonna Give You Up",
  source: "youtube"
};
```

## Melhores Práticas

1. **Use os tipos para validação**: Utilize os tipos para validar valores antes de passá-los para as funções do Moonlink.js.

2. **Documente os valores esperados**: Ao criar funções que aceitam valores de tipos específicos, documente os valores esperados.

3. **Verifique valores em tempo de execução**: Mesmo com TypeScript, é uma boa prática verificar valores em tempo de execução para garantir que eles sejam válidos.

4. **Forneça valores padrão**: Ao criar funções que aceitam tipos, forneça valores padrão quando apropriado.

5. **Trate todos os casos**: Ao lidar com tipos em instruções switch, certifique-se de tratar todos os casos possíveis.
