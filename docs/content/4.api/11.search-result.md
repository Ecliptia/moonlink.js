#title
SearchResult Class

#description
Class responsible for processing and representing search results returned by Lavalink. It provides a consistent interface for accessing tracks, playlists, and error information.
<br>
```js
new SearchResult(req, options)
```
::

::alert{type="info" icon="lucide:info"}
The SearchResult class is returned by the Manager's search() method and contains all information about the search results.
::

## Overview

::card{icon="lucide:box"}
#title
Properties

#description
Core properties of the SearchResult class.
<br>
<h5>Available Properties</h5>

#content
| Property | Type | Description |
|----------|------|-------------|
| `query` | `string` | The search query used to obtain the results |
| `source` | `string` | The source platform of the search (youtube, soundcloud, etc.) |
| `loadType` | `string` | The type of search result (`track`, `playlist`, `search`, `empty`, `error`) |
| `tracks` | `Track[]` | Array of tracks found in the search |
| `playlistInfo` | `IPlaylistInfo` | Information about the playlist (if loadType is `playlist`) |
| `error` | `string` | Error message if the search failed |
::

## Result Types

::card{icon="lucide:list"}
#title
Result Types

#description
The loadType property can have the following values.
<br>
<h5>Available Types</h5>

#content
### track
::field{name="track" type="string"}
Indicates that a single track was loaded. The tracks array will contain only one track.
::

**Example**
```js
{
  loadType: "track",
  tracks: [
    {
      track: "base64-encoded-track",
      info: {
        identifier: "dQw4w9WgXcQ",
        title: "Rick Astley - Never Gonna Give You Up",
        author: "Rick Astley",
        length: 213000,
        isStream: false,
        uri: "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
        sourceName: "youtube"
      }
    }
  ],
  playlistInfo: {
    name: null,
    selectedTrack: -1
  }
}
```

### playlist
::field{name="playlist" type="string"}
Indicates that a playlist was loaded. The tracks array will contain all tracks and playlistInfo will have playlist details.
::

**Example**
```js
{
  loadType: "playlist",
  tracks: [
    {
      track: "base64-encoded-track-1",
      info: { /* track 1 information */ }
    },
    {
      track: "base64-encoded-track-2",
      info: { /* track 2 information */ }
    }
  ],
  playlistInfo: {
    name: "My Playlist",
    selectedTrack: 0
  }
}
```

### search
::field{name="search" type="string"}
Indicates that the search returned multiple results. The tracks array will contain all found tracks.
::

**Example**
```js
{
  loadType: "search",
  tracks: [
    {
      track: "base64-encoded-track-1",
      info: { /* track 1 information */ }
    },
    {
      track: "base64-encoded-track-2",
      info: { /* track 2 information */ }
    }
  ],
  playlistInfo: {
    name: null,
    selectedTrack: -1
  }
}
```

### empty
::field{name="empty" type="string"}
Indicates that no results were found. The tracks array will be empty.
::

**Example**
```js
{
  loadType: "empty",
  tracks: [],
  playlistInfo: {
    name: null,
    selectedTrack: -1
  }
}
```

### error
::field{name="error" type="string"}
Indicates that an error occurred during the search. The error property will contain the message.
::

**Example**
```js
{
  loadType: "error",
  tracks: [],
  playlistInfo: {
    name: null,
    selectedTrack: -1
  },
  error: "Could not load track: 404 Not Found"
}
```
::

## Usage Examples

::card{icon="lucide:code"}
#title
Basic Usage

#description
Example of using the SearchResult class.

#content
```js
// Create a search result instance
const searchResult = new SearchResult(response, {
  query: "never gonna give you up",
  source: "youtube",
  requester: message.author
});

// Access the search results
console.log(`Search query: ${searchResult.query}`);
console.log(`Source: ${searchResult.source}`);
console.log(`Load type: ${searchResult.loadType}`);

// Process tracks based on load type
switch (searchResult.loadType) {
  case "track":
  case "search":
    console.log(`Found ${searchResult.tracks.length} tracks`);
    break;
    
  case "playlist":
    console.log(`Found playlist: ${searchResult.playlistInfo.name}`);
    console.log(`Total tracks: ${searchResult.tracks.length}`);
    break;
    
  case "empty":
    console.log("No results found");
    break;
    
  case "error":
    console.error(`Error: ${searchResult.error}`);
    break;
}
```

## Best Practices

::card{icon="lucide:list-checks"}
#title
Best Practices

#description
Guidelines for using the SearchResult class effectively.

#content
1. **Check Load Type First**
   - Always check the `loadType` before accessing tracks or playlist information
   - Handle each load type appropriately in your code

2. **Error Handling**
   - Check for the "error" load type and handle errors gracefully
   - Use try-catch blocks when working with search results

3. **Track Processing**
   - Process tracks based on the load type
   - Handle empty results appropriately

4. **Playlist Handling**
   - Check if `playlistInfo` exists before accessing playlist properties
   - Process all tracks in a playlist when needed

5. **Source Management**
   - Specify the source when possible for more accurate results
   - Handle different sources appropriately in your code
