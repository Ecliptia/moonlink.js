#title
Plugin Class

#description
A base class for all Moonlink.js plugins. It allows you to extend functionality and add custom features without modifying the core code.
<br>
```js
new Plugin(options)
```
::

::alert{type="info" icon="lucide:info"}
Plugins are a powerful way to customize Moonlink.js for your specific needs without modifying the core library.
::

## Overview

::card{icon="lucide:box"}
#title
Properties

#description
Core properties of the Plugin class.
<br>
<h5>Available Properties</h5>

#content
| Property | Type | Description |
| -------- | ---- | ----------- |
| `name` | `string` | The name of the plugin. |
| `version` | `string` | The version of the plugin. |
| `description` | `string?` | A brief description of the plugin (optional). |
| `author` | `string?` | The author of the plugin (optional). |
| `manager` | `Manager` | The Manager instance (available after loading). |
::

::card{icon="lucide:settings"}
#title
Configuration Options

#description
Options for configuring a Plugin instance.
<br>
<h5>Plugin Options</h5>

#content
| Option | Type | Default | Description |
| ------ | ---- | ------- | ----------- |
| `name` | `string` | Required | The name of the plugin. |
| `version` | `string` | Required | The version of the plugin. |
| `description` | `string` | `undefined` | A description of the plugin. |
| `author` | `string` | `undefined` | The author of the plugin. |
| `minVersion` | `string` | `undefined` | The minimum required version of Moonlink.js. |

::alert{type="warning" icon="lucide:alert-triangle"}
The `name` and `version` options are required. Without them, the plugin will not function correctly.
::

## Extending Structures with Plugins

Plugins can also be used to extend existing structures in Moonlink.js. This allows you to add custom functionality to classes like `Player`, `Queue`, and others.

### Example: Extending the Player Class

```js
const { Plugin, Structure } = require('moonlink.js');

class MyPlugin extends Plugin {
  constructor() {
    super({
      name: 'MyPlugin',
      version: '1.0.0',
      description: 'An example plugin that extends Player',
      author: 'Your Name'
    });
  }
  
  load(manager) {
    super.load(manager);
    
    // Extend the Player class
    Structure.extend('Player', Player => {
      return class CustomPlayer extends Player {
        constructor(manager, options) {
          super(manager, options);
          this.customProperty = 'custom value';
        }
        
        customMethod() {
          return this.customProperty;
        }
      };
    });
  }
  
  unload() {
    // Clean up resources
    super.unload();
  }
}

// Use the plugin
const manager = new Manager({
  nodes: [...],
  plugins: [new MyPlugin()]
});
```

## Usage Examples

::card{icon="lucide:code"}
#title
Basic Setup

#description
Example of creating and using a plugin.
<br>
<h5>Code Example</h5>

#content
```js
const { Plugin } = require('moonlink.js');

class MyPlugin extends Plugin {
  constructor() {
    super({
      name: 'MyPlugin',
      version: '1.0.0',
      description: 'An example plugin',
      author: 'Your Name'
    });
  }
  
  load(manager) {
    super.load(manager);
    
    // Add functionality to manager
    manager.on('trackStart', (player, track) => {
      console.log(`Playing: ${track.title}`);
    });
  }
  
  unload() {
    // Clean up resources
    super.unload();
  }
}

// Use the plugin
const manager = new Manager({
  nodes: [...],
  plugins: [new MyPlugin()]
});
```

This example shows basic plugin creation with events.
