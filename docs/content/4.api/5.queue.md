The `Queue` class manages a player's track queue, allowing you to add, remove, and manipulate tracks. The queue is persistent and synchronized with the internal database.

::alert{type="info" icon="lucide:info"}
Queue is an essential component for managing multiple tracks in a music bot. It provides methods for adding, removing, and manipulating track order, with automatic persistence.
::

## Properties

| Property | Type | Description | Default |
|----------|------|-------------|---------|
| `database` | `Database` | Database instance for persistence | Required |
| `guildId` | `string` | Guild ID associated with the queue | Required |
| `tracks` | `Track[]` | Array containing all tracks in queue | `[]` |
| `size` | `number` | Number of tracks in queue | `0` |

## Example Usage

::card
---
icon: lucide:code
---

#title
Complete Example

#description
A complete example of working with the Queue class

#content
```js
// Create a player
const player = manager.createPlayer({
  guildId: '123456789012345678',
  voiceChannelId: '123456789012345678',
  textChannelId: '123456789012345678'
});

// Add a track to queue
player.queue.add(track);

// Check queue size
console.log(`Tracks in queue: ${player.queue.size}`);

// Shuffle queue
player.queue.shuffle();

// Remove a track
player.queue.remove(2);

// Clear queue
player.queue.clear();

// Handle events
manager.on('queueEnd', (player, track) => {
  console.log(`Queue finished playing in guild ${player.guildId}`);
});

manager.on('playerTriggeredShuffle', (player, oldQueue, newQueue) => {
  console.log(`Queue was shuffled in guild ${player.guildId}`);
});
```
